@embedding(model_name=EMBEDDING_MODEL_ID)
@performance_monitor(threshold_ms=200)
def get_query_embedding(query: str) -> list[float]:
    """Embeds the user query using the configured local model."""
    prefixed_query = f"{EMBED_QUERY_PREFIX}{query}" if EMBED_QUERY_PREFIX else query
    vec = embed(prefixed_query, model=EMBEDDING_MODEL_ID, return_format="list")
    return vec

from jet_telemetry import chain, get_trace_url
from src.config import PHOENIX_URL
from src.models.schemas import JobResult, SearchRequest, SearchResponse
from src.services.db_service import get_date_threshold, search_jobs_hybrid
from src.services.embedding_service import get_query_embedding
@chain(name="job-search-level-1")
async def execute_search(request: SearchRequest) -> SearchResponse:
    """Level 1 Workflow: Date Filter -> Embed -> Hybrid DB Search"""
    threshold = get_date_threshold(request.days_back)
    query_vec = get_query_embedding(request.query)
    raw_results = await search_jobs_hybrid(
        query_vector=query_vec,
        posted_date_threshold=threshold,
        top_k=request.top_k,
    )
    results = [JobResult(**r) for r in raw_results]
    return SearchResponse(results=results, trace_url=get_trace_url(PHOENIX_URL))

Key Architectural Decisions

Layer
Folder
Responsibility
Models
src/models/
Pydantic schemas only — no business logic
Services
src/services/
External integrations (DB, embeddings) — decorated with telemetry
Workflows
src/workflows/
Orchestration / chains — composes services into business logic
Routes
src/routes/
Thin HTTP layer — validates input, delegates to workflows, handles errors
App
src/main.py
Factory pattern — wires everything together, single entrypoint

Why This Structure Works

  1. No sys.path hacks — All imports use absolute src.* paths. Run from the level_1/ directory and Python resolves everything naturally.
  2. Change detection is clean — reload_dirs=["src"] means uvicorn only watches source files. No more __pycache__ false positives.
  3. Separation of concerns — Routes don't know about SQL. Services don't know about HTTP. Workflows compose services without caring about transport.
  4. Scalable — Adding a new endpoint means adding a file in routes/, a workflow in workflows/, and registering the router in main.py. No monolithic file growth.
  5. Testable — Each layer can be unit tested independently. Mock services when testing workflows. Mock workflows when testing routes.
